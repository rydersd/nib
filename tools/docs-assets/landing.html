Agent-consumable wireframe framework

The wireframe
framework
for agents.

Paper-rough to pixel-polished — one framework, every fidelity. Nib hands an agent shared CSS, JS and reference docs so it can generate consistent, professional wireframes for any project.

Get started → How it works

npx create-nib my-project  ·  MIT  ·  zero build step

01

Built for agents

An agent reads the reference docs, copies a starter, and emits a page that already obeys every token, rule and convention.

02

Consistent by construction

Shared CSS and JS, one design-token system, and surface overlays for Slack, Salesforce and internal portals — never hardcoded.

03

Honest fidelity

Napkin, Blueprint or Polished. The aesthetic itself tells a reviewer how settled the design is — and now, how grounded.
